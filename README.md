# SpaceWeaver

SpaceWeaver is an intelligent space design platform that transforms chaos into perfect harmony.

## Features

- **Space DNA**: Analyzes spatial geometry, natural light paths, and ergonomic flow to generate your room's unique fingerprint.
- **Cinematic WebGL Hero**: Experience the magnetic arrangement of your space in real-time.
- **Affiliate Integration**: Curated furniture recommendations based on your space's aesthetic.

## Tech Stack

- React 18
- TypeScript
- Vite
- Three.js & React Three Fiber
- GSAP & Framer Motion
- Tailwind CSS

## Getting Started

1. Install dependencies:
   ```bash
   npm install
   ```

2. Start the development server:
   ```bash
   npm run dev
   ```
